Conecta Upstash (Redis gratis) para poder guardar cambios desde aquí.

  1. Crea una cuenta gratis en upstash.com
  2. Crea una base de datos Redis (plan gratuito, un clic)
  3. En su panel, copia UPSTASH_REDIS_REST_URL y UPSTASH_REDIS_REST_TOKEN
  4. Pégalas en Vercel → tu proyecto → Settings → Environment Variables, con esos mismos nombres, y vuelve a hacer deploy
